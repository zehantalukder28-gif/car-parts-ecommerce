# Performance ApexAuto — Modern Stateful E-Commerce Dashboard

A premium, high-performance automotive parts dashboard built from the ground up using React, TypeScript, and Tailwind CSS. This application features state-driven client-side data filtering, memory-safe URL routing, and a custom asynchronous AI diagnostics assistant.

👉 **Live Repository:** [https://github.com/zehantalukder28-gif/car-parts-ecommerce](https://github.com/zehantalukder28-gif/car-parts-ecommerce)

## ⚡ Core Engineering & Architecture Features

* **Custom Platinum-Cyan Design System:** Personally engineered the entire visual theme using an ultra-clean, luxury gallery-grade Platinum Light background (`#F8FAFC`). Paired it with high-contrast charcoal typography (`#1A1A1A`) for an editorial aesthetic, accented by sharp neon-cyan highlights to represent raw speed and automotive performance.
* **Asymmetric Editorial Layouts:** Broke away from boring, standard block templates by designing custom layout flows:
  * **Floating Vehicle Lookup:** Positioned the primary vehicle configuration widget using absolute layers and negative margins so it floats cleanly across layout sections.
  * **Staggered Catalog Grid:** Programmed a mathematical offset checker into the product mapping logic to drop alternating cards down, creating a high-end magazine display.
  * **Horizontal Scroll Tracks:** Converted rigid category blocks into custom left-to-right swipe carousels with hidden browser scrollbars and manual navigation controls.
* **Memory-Safe Search & URL Filtering:** Implemented advanced routing parameters using React Router. When a user queries a vehicle configuration, the application safely injects parameters straight into the URL (`/products?make=bmw&model=m4`) without forcing a harsh screen flash or wiping active application state memory.
* **Stateful Asynchronous Troubleshooting Engine:** Built an interactive tech assistant from scratch. It handles message logging inside local React state arrays, simulates server processing times using asynchronous loading delays, and uses a built-in text scanner to automatically alter its own UI layout to hand the user a live-engineer escalation button when a complex question is detected.
* **Ultrawide Monitor Optimization:** Engineered protective structural boundaries (`max-w-7xl mx-auto`) around all major layouts, ensuring the user interface stays perfectly centered and anchored regardless of giant screen resolutions or browser zoom adjustments.
